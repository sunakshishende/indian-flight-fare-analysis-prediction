
# INDIAN FLIGHT FARE ANALYSIS AND PREDICTION

## 1. Project Overview
This project analyzes Indian flight ticket prices and develops
a Machine Learning model to predict flight fares.

## 2. Objectives
- Analyze flight ticket prices.
- Study airline-wise fare variations.
- Analyze routes, stops and flight duration.
- Understand booking window and departure time effects.
- Build a Machine Learning prediction model.
- Create an interactive flight fare prediction interface.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- IPyWidgets

## 4. Dataset Information
Dataset: Clean_Dataset.csv
Total Records: 300153
Total Columns: 13
Unique Airlines: 6
Unique Routes: 30

## 5. Machine Learning
Selected Model: Random Forest
MAE: 1058.33
RMSE: 2678.33
R2 Score: 0.9861

## 6. Project Output
The project provides:
- Exploratory Data Analysis
- Data visualizations
- Route analysis
- Fare prediction model
- Interactive prediction interface

## 7. Conclusion
The project uses historical flight data to understand
flight fare patterns and estimate ticket prices based
on selected flight details.
