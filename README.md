# Indian Flight Fare Analysis and Prediction

## Project Overview
This project analyzes Indian flight ticket prices and predicts estimated fares using Python, Exploratory Data Analysis (EDA), and Machine Learning.

## Objectives
- Analyze flight fare patterns across airlines and routes.
- Understand the impact of booking days, travel class, duration, and stops.
- Build machine learning models to predict flight ticket prices.
- Develop an interactive flight fare prediction interface.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook
- IPyWidgets

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Model Evaluation
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared Score (R²)

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open the Jupyter Notebook.
4. Run the notebook cells sequentially.
